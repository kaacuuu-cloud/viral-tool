# MVP 로드맵 v2 — 바이럴 콘텐츠 분석 도구 (컨셉보드용)

## 목표
검색어 기반으로 유튜브 영상을 수집·필터링한 뒤, NotebookLM CLI로 영상을 분석하고,
광고 판별 + 제품 인사이트를 추출하여 컨셉보드용 테이블로 정리하는 도구

## 최종 산출물 (결과 테이블 컬럼)
| NO  | 제품명             | 투고일        | 플랫폼            | 계정명           | 조회수  | 좋아요수 | 댓글수 | URL         | 광고여부 | 비고(인사이트)                      |
| --- | --------------- | ---------- | -------------- | ------------- | ---- | ---- | --- | ----------- | ---- | ----------------------------- |
| 1   | 프라엘 수퍼폼 갈바닉 부스터 | 2025.12.21 | YouTube Shorts | @with_yoomina | 9.8만 | 3566 | 187 | https://... | 광고임  | [기기 리뷰] 갈바닉 모드 피부 탄력 효과 강조... |

### 광고여부 판별 기준
- 영상 제목/설명에 "유료광고", "협찬", "제공", "AD", "Sponsored" 등 포함 여부
- 영상 본문/자막에서 광고 관련 발화 탐지
- 화면 내 "광고" 텍스트 존재 여부
- 결과: **광고임 / 광고아님 / 판별못함**

### 비고(인사이트) 필수 포함 항목
- 어떤 기기에 대한 리뷰인가? (제품명 + 모델명)
- [선택] 비교 영상 vs 단일 리뷰 구분
- [선택] 기기별 장단점 (스펙과 매칭, 보수적 분석)

## 사용 기술
- YouTube Data API v3 (무료, 일 10,000 유닛)
- notebooklm-py CLI (오픈소스, 무료)
- Next.js + Tailwind CSS
- Vercel 배포 (무료)

## API 유닛 사용량 계산
- search.list: 100유닛/회
- videos.list: 1유닛/회 (검색 1회당 50개 = 50유닛)
- **검색 1회 = 약 150유닛** → 하루 약 66회 검색 가능
- NotebookLM: notebooklm-py 사용 시 추가 비용 없음
